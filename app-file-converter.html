File Converter

GitHub

A universal multi-platform file format converter for images, audio, video, and documents. Runs entirely offline — no upload, no cloud, no waiting.

Desktop Python Utility Offline

About the App

File Converter is a desktop application built for people who regularly need to convert files between formats. Rather than uploading files to a web service, everything is processed locally using FFmpeg and Pillow — making it fast, private, and reliable even without internet.

The interface is clean and direct: drag in a file, pick your output format, and click Convert. Batch processing lets you convert multiple files in one run.

Supported Formats

Images

Convert between PNG, JPG, WEBP, BMP, GIF, TIFF, and more.

Audio

Convert between MP3, WAV, FLAC, OGG, AAC, and other audio formats.

Video

Convert between MP4, MKV, AVI, MOV, WebM, and other video formats.

Batch Processing

Convert multiple files at once with a single click and shared settings.
