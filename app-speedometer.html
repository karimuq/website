Speedometer

GitHub

A GPS-based mobile speedometer application for real-time speed tracking and trip velocity metrics. Designed for drivers, cyclists, and anyone who wants accurate on-device speed data.

Android Java GPS Utility

About the App

Speedometer uses the device GPS to calculate and display your current speed in real time. It provides a large, easy-to-read digital speedometer interface — clean and minimal so you can glance at it while on the move.

The app also logs trip statistics including max speed, average speed, and total distance, giving you a full picture of each journey without needing an internet connection.

Features

Real-Time Speed

Live GPS-derived speed display updated every second in your chosen unit.

Unit Toggle

Switch between km/h and mph with a single tap.

Trip Stats

Tracks max speed, average speed, and distance per session.

Offline

No internet required — all calculations run on-device via GPS hardware.
