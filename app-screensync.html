ScreenSync

Concept Demo

A screen-time accountability app concept that lets you share your daily phone usage with trusted friends and family to build healthier digital habits together.

Web Application JavaScript Interactive Concept Productivity

About the Concept

ScreenSync is a design and UX prototype exploring social accountability as an antidote to habitual smartphone overuse. The core insight: sharing verified screen-time trends with people you trust creates gentle, supportive social encouragement to unplug.

This live web prototype demonstrates the end-to-end interface and core interactions — categorized daily usage visualizers, peer accountability circles, and streak gamification for staying under personal thresholds.

How to Use

Exploring the interactive prototype experience:

1

Launch Prototype

Interact with the live web application frame below or open it in full-screen view.

Key Capabilities

Usage Dashboard

Visual breakdown of daily screen time by app category and total hours.

Friend Feed

See your friends' daily screen time summaries to stay accountable together.

Goal Streaks

Set a daily screen time goal and track how many days in a row you hit it.

Privacy Controls

Choose exactly what you share and with whom — nothing is public by default.
