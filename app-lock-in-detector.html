GitHub

Desktop Python AI / CV Productivity

About the App

The Lock In Detector is a Python desktop application that runs a lightweight computer vision model on your webcam feed. It monitors your hands and environment in real time to detect when a phone-shaped object is picked up.

When distraction is detected, the app triggers a configurable alert — sound, visual overlay, or both — to break your habit and redirect your attention back to the screen. Everything runs 100% offline with no data ever leaving your machine.

Features

Webcam Detection

Uses computer vision to monitor hand and phone position in the camera frame.

Instant Alerts

Audio and visual alerts trigger the moment distraction is detected.

100% Offline

All inference runs locally — no cloud, no API calls, no data collection.

Session Stats

Tracks how many times you were distracted per session so you can improve over time.
