The Lock In Detector

v1.0.0 — Available

An AI-powered offline desktop utility that uses your webcam to detect when you pick up your phone, then alerts you to stay locked in and focused.

Windows Desktop Python AI / OpenCV Productivity Open Source

About the App

The Lock In Detector is a desktop application that runs a lightweight computer vision model on your local webcam feed. It monitors your hands and workspace in real time to detect when a phone-shaped object is picked up during work sessions.

When distraction is detected, the app triggers configurable intervention alerts — sound alarms, full-screen visual overlays, or both — to interrupt reflexive scrolling and redirect focus to productive work. Everything runs 100% offline with zero cloud transmission.

How to Use

Locking into deep work with AI computer vision takes less than a minute:

1

Download & Launch

Download the latest release package from GitHub and run the executable on Windows.

2

Position Webcam

Angle your webcam so it captures your keyboard, desk surface, and natural posture.

3

Activate Session

Click Start Focus. The CV pipeline begins monitoring hand movements and mobile screen glares.

4

Stay Locked In

If you grab your phone, an alert sounds immediately to snap you back to your priorities.

Key Capabilities

Real-Time Webcam Detection

Uses computer vision models to track hand position and phone usage in the camera frame.

Instant Intervention Alerts

Audio alarms and visual HUD prompts trigger the exact moment distraction occurs.

100% Offline Inference

All vision models execute locally on-device — no cloud streaming, no recordings, zero latency.

Session Analytics

Logs distraction occurrences per deep work block to measure self-discipline growth.
